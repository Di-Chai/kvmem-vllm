## 行为

对照本机 qw3 `src/kvmem_refresh_policy.hpp` 的跨轮策略：

- 新用户任务用公开 Query 建立选页，不自动生成私有 Query。
- 同一任务的工具回传沿用选页 epoch；累计输入与接受输出达到 T 后，
  在原窗口内生成私有检索 Query，再执行一次 Query 图传播和选页。
- 私有生成预留包含在 K+G 内。超大工具回传超过 G 时先做必要的 pressure
  摄入，再生成私有 Query。私有内容不提交为公开输出或历史 attention。
- decode 达到阈值后限制投机步长，并在已接受的安全文本边界刷新。
  接近容量且工具／代码片段未闭合时，用缓存的原 Query 回退。
- 空输出、结构化输出、未自然结束或容量不足时，记录原因并回退到原 Query。
  两种 Query 都不可用时，在选页提交前报错，不能把 attention pressure
  冒充 Query 刷新并推进 epoch。
- 原 Query Q 是有上限的 CPU 缓存。P/M 检查点保存对应的不可变版本，
  并计入检查点额度；恢复不会拿未来分支的 Query。额度失败保持原检查点。

自动生命周期目前限定同步刷新，实际 GPU 验收为 DFlash7/FULL/FP8 KV。
异步 MTP 自动生命周期尚未开放，配置会明确拒绝。MTP 原有显式 Query
路径仍保留。原生历史事务要求 32-token 封页，因此 decode 安全点可能
晚于 qw3 的逐 token 安全点；没有宣称两者逐 token 调度完全一致。
DSH 显式指定的 recent=2048 仍是保留上限，本次没有新增自适应尾部强制保留。
