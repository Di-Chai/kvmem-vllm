# FP8 raw K 迁移（2026-10-16）

服务端 CPU historical KV 和 GPU raw-K cache 统一使用 FP8 E4M3FN 的 pre-RoPE K。
这对应 qw3 在 `QW3_KV_DTYPE=fp8` 时的 immutable raw-K 类型。
`raw` 表示 RoPE 前坐标，不表示未量化。

## 数据路径

- 模型仍产生 BF16 Q/K/V；历史捕获把 pre-RoPE K 以 unit scale 转为 FP8，
  范围限制为 ±448。不修改模型原生 forward 的激活或原生 KV 写入。
- CPU 归档、D2H 包、部分尾页和 GPU raw-K cache 均保存这份 1 字节 raw K。
  V 保留按原生 V scale 编码的 FP8 字节。
- 封页 MeanK 从 FP8 源展开、按 token 顺序作 FP32 累加，最终索引保存 FP16。
  target 层参与评分；MTP 的 K/V 保存与恢复，但不混入 target MeanK 评分。
- 恢复时展开 raw K，以 FP32 重新施加 dense-position RoPE，再按原生 K scale
  一次转换为目标 FP8。中间不增加 BF16 或 FP8 舍入。
- 普通装配、packed、direct-pinned、split/raw-cache、resident V 复用都支持新格式。
  显式构造的 BF16/FP16 测试 authority 仍保留，用于独立参考回归。
- cache geometry 标记 `schema=2` 和
  `archive_codec=raw_fp8_e4m3fn_v_fp8_e4m3fn_v1`；CPU 准入、启动预留和
  NIAH / MemoryAgentBench / LongMemEval 的历史额度同步按新字节数计算。
  不提供旧格式持久化快照的就地转换；当前 CPU 历史是进程内临时状态。

## 容量

当前模型的 16 个 target full-attention 层加 1 个 MTP 层、4 KV heads、head dim 256：

| 历史主体 | 旧版本 | 新版本 |
| --- | ---: | ---: |
| 每个元素 raw K + V | 2 + 1 字节 | 1 + 1 字节 |
| 每 token | 52,224 字节 | 34,816 字节 |
| 每用户 256K tokens | 13.690 GB / 12.75 GiB | 9.127 GB / 8.5 GiB |

历史 K/V 主体减少三分之一，raw K 单独减少一半。上述值不含 MeanK 索引、部分页、
CPU staging、Q 缓存、recurrent 检查点、模型进程和其他运行开销。
100 GB 仅按满额历史主体计算可放 10 个用户；这不是已验证的用户并发上限。
GPU active KV 格式本来就是 FP8，本次不将其容量收益重复计算。

## 验证口径

raw K 从 BF16 量化为 FP8 有数值损失。冷恢复所得 K 不应再与原生 forward
从 BF16 激活直接写出的 rotated K 强制相等。验证时使用独立 CPU Torch 计算，
从不可变 FP8 历史重建预期 K/V，再与 GPU 装配逐字节比较，标记为
`fp8_immutable_rebuild`。热驻留沿用原始 terminal-window 字节预期，标记为
`native_terminal_window`。V、recurrent 和独立 draft 状态继续作精确校验。
故意破坏字节的测试必须拒绝恢复，不能用容差放宽来掩盖装配错误。

本次真实模型验收使用 NVFP4、FP8 native KV、MTP k=4、compiled graph，四个
独立用户各 128K 输入、两轮各 257 输出，中间追加 512-token 工具结果。
K=64K，G=32K，历史上限 256K，CPU archive，分别检查冷恢复与热驻留恢复。
这是格式迁移的正确性检查，不是新的吞吐、容量或任务准确率 benchmark。

CPU 回归通过 178 项；GPU 回归通过 50 项、跳过 10 项已有的条件化用例。
覆盖所有有限 E4M3 编码的展开、accepted-prefix / rejected suffix、批量维护、
MeanK 封页、rewind、四种装配路径、尾块、raw-cache 命中和 resident V 移动。
真实模型冷恢复组：4 个用户共 8 次请求全部成功，4 次跨轮恢复全部通过逐字节
校验。每次覆盖 17 个 attention 层（含 1 个 MTP 层）、96 个 recurrent tensors；
实际工作窗口为 65,920 tokens。运行保持 compiled graph，使用 CPU 历史，无 KV
磁盘读写。`cold-audit/restore-gate.json` 独立检查通过 4/4 次恢复。

原始双组测试在冷恢复完成后因另一项 qw3 GPU 任务进入而自动停止，只退出本次
服务，没有停止外部任务。原始 `model/status.json` 保留失败与原因；`cold-audit`
仅引用已完成的 A0 冷恢复组，不将未完成的 P1 组计为通过。热驻留真实模型补测
位于 `hot-model/`；因外部测试继续占用 GPU，已取消本次补测队列，未将其计为通过。
GPU 层的 raw-cache / resident V 路径已通过。
之后仅在验证器中修正压力恢复后工作窗口长度的读取，新增 CPU 用例覆盖较小的
pressure frame；不会改变这两组非 pressure-restore 请求的执行与比较结果。

所有结果和原始日志保存在 `artifacts/fp8-raw-k-20261016/`。这些运行开启了昂贵的
逐字节校验且包含首次内核编译，不将其耗时作为吞吐或恢复延迟 benchmark。
本次未重跑 NIAH / MemoryAgentBench / LongMemEval 准确率对照。
