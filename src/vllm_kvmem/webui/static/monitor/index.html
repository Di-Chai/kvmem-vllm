说明与致谢

页面每秒刷新；显卡指标为整卡读数，可能包含其他程序。

指标说明

请求统计随所选请求变化。上下文用量为输入与已生成 token 之和；输出预算表示已用额度，不表示完成进度。生成速度包含已接受的思考 token。

上下文用量不等于显存中的 KV 缓存量；输入 token 复用不等于历史缓存命中。

曲线从打开页面时开始记录。后台每 5 秒刷新，断线保留最后读数并标记过期；缺失数据显示“未采集”或“—”。

界面参考 Strata 仪表盘，使用 Outfit 字体。感谢开源作者。

开源许可

Strata · MIT · Outfit · SIL OFL 1.1

接收速率说明

速率按首批之后收到的已接受 token 计算，包含思考 token；受传输和接收时间影响，不等于引擎内部解码吞吐。

预填充说明

处理新输入的速度
